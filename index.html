Border: Qal'a Devorini Quramiz!

border-width (qalinlik), border-style (uslub) va border-radius (burchaklar yumaloqligi) bilan tanishamiz.

🏰
Sehrli Qal'a
Devor Qalinligi (border-width): 6px
Burchak Yumaloqligi (border-radius): 16px
style.css Devor Qoidalari
.qala { border-width: 6px; border-style: solid; border-color: #feca57; border-radius: 16px; }
5-Dars

Margin va Padding Jangi (Eng Muhim Farq!)

Padding — quti ichidagi yumshoq masofa. Margin — qo'shnilar bilan oraliq tashqi masofa!

🐕 Qo'shni Kuchukcha
Margin: 20px ↔️
🐱
Padding: 20px (Ichki qulaylik)
🛋️ Padding (Quti ichki kengligi): 20px
Mushukchaga ichkarida ko'proq joy ochiladi!
🚪 Margin (Qo'shnidan uzoqlashish): 20px
Butun quti qo'shnidan uzoqlashadi!
style.css Box Model
.mushuk-qutisi { padding: 20px; /* Ichki masofa */ margin-left: 20px; /* Tashqi masofa */ }
